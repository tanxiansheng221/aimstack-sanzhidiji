## 0. 起点命题（用户设想）

「权重内部世界有海量神经节点，喂数据时全体同时计算，按理说应该可以直接吃透。」

E6 战役已证明：在权重容器里这个命题不成立（计算并行 ≠ 学习并行，梯度冲突 +
记忆解远多于规则解）。本报告回答：**什么容器能让这个命题成立？**

## 1. 四条候选容器的扫描结论

| 候选 | 核心机制 | 对设想的匹配度 | 判决 |
|---|---|---|---|
| **HDC/VSA 超维计算** | 万维近正交向量 + 绑定/叠加代数，局部运算无全局梯度 | **逐字吻合**（海量节点、大部分闲置、分摊、写入即保存） | ✅ 选定 |
| Forward-Forward 局部学习 | 层级局部目标，无反向传播 | 部分吻合（仍需迭代训练） | 备选（语言侧改造用） |

| 储备池计算 | 固定随机核 + 线性读出 | 低（读出仍是训练） | 淘汰 |

关键背景：HDC 的学科起源正是「小脑在高维分布式表征上运算」——用户的小脑直觉
与该领域的出发点重合。文献线（arXiv:2111.06077 综述、pyhdc/holovec 工程库、
Purdue VSA 硬件实现）成熟度足够支撑原型。

## 2. 数学核心（为什么这个容器「写入即吃透」）

取 m 级量化相位的复数超维向量：

    P_r[i] = exp(i·2π·r·k_i / m)        k_i 为每维随机频率，D 维

绑定运算 = 逐元素复数乘法，则**精确成立**（非近似）：

    P_r ⊙ P_s = P_{(r+s) mod m}

即：**模 m 加法的规则不在权重里，在容器的代数结构里**。数字编码为相位向量后，
「计算 a+b mod m」就是一次逐元素乘法——没有训练、没有梯度、没有误差累积。

与傅里叶特征的合流：文献（arXiv:2406.03445）发现预训练 LLM 靠 embedding 中的
傅里叶特征做算术——HDC 的相位编码就是把这个隐式机制**显式化为容器代数**。
两条独立线索收敛到同一数学结构。

## 4. 容量标度律（实测 + 理论）

叠加存储信噪比：SNR ≈ √(D/K)（信号 = D 相干叠加，噪声 = √(K·D) 随机相位）。
实测容量 ≈ D/10（m=8 时 200 对 @ D=2048）。

| D（节点数） | 预期容量（100% 回忆） |
|---|---|
| 2,048（本次原型） | ~200 对 |
| 65,536 | ~6,400 对 |
| 1,048,576（纯 C 位打包可行） | ~10 万对 |
| 分区 N 块（海马体式多库） | ×N |

## 5. 诚实边界（这个容器不能干什么）

- **代数内置的规则**（模加法、循环结构、位次）→ 精确、零训练、零遗忘 ✅
- **一次性联想**（key→value）→ 一次写入，容量随 D 标度 ✅
- **软规律**（语感、语法、情绪）→ **做不到**。HDC 没有「模糊泛化」的梯度机制
- 结论：它是权重的**互补容器**，不是替代品。分工：精确/结构化 → HDC；
  模糊语言 → 权重；确定执行 → C 核

## 6. 切入点与工程路线（已定）

1. **纯 C 实现**（铁律对齐：零第三方依赖）：D=65536 相位向量可用
   int16 相位表 + 查表乘法；二值 HDC 变体可用位运算（XOR=绑定, 多数票=叠加）
2. **接入形态**：作为 AVS 架构第三个外挂容器——
   权重（语言）+ KB（事实检索）+ **HDC（结构化精确记忆/运算）** + C 核（执行）
3. **首个集成实验**：把 152M 的数字 token 表示换成 HDC 相位编码输入
   （对齐傅里叶特征注入方案），验证「语言权重 + HDC 数字容器」混合推理
4. **多块分区**：ART 式 vigilance 分配新块（新类知识进新块，旧块零扰动）
   ——用户「海马体分zure」设想的工程化

将用户设想逐条映射为同一 16384 维相位基质上的三种存储模式（分区共存，

| 用户设想 | 容器实现 | 实测（D=16384） |
|---|---|---|
| 大量节点里面没东西 | 2^16384 近正交空间，仅用 600 条 | 闲置率 >99.99% |
| 节点包裹三区 | 同一基质三种模式：皮层=固化槽位 / 海马体=叠加库 / 小脑=绑定代数 | 分区共存 ✓ |
| 喂数据同时计算直接吃透 | 一次写入（叠加分摊），零梯度零迭代 | T1: 300 新事实一次写入回忆 **100/100**；T2: 算术 **5000/5000** 零训练 |
| 汇入海马体→皮层（巩固） | 高频条目固化进槽位库 | T3: 固化条目皮层回忆 **50/50** |
| 不容易忘 | 分区物理隔离（写新不碰旧） | T4: 再学 300 新事实后 旧 49/50 / 新 46/50 |
| 分摊 | 叠加库 | 同上 |
| 模糊理解（变体提问可召回） | 噪声 key 召回 | T5: 10%/20%/30% 噪声 → 84%/72%/56% |
| **不幻觉（知道自己不知道）** | top1-top2 间隔 z 分数置信度，低置信拒答 | T6: 200 未知问题 **拒答 200/200，幻觉率 0.0%** |

关键工程发现：
- **置信度统计量是幻觉消除的核心**：绝对相关度阈值会被噪声 Rayleigh 尾部击穿
  （12800 次采样最大值天然冲到 0.5+）；top1-top2 间隔 z 分数把真信号（间隔≈1）
  与噪声（间隔≈0）锐利分离——这是权重容器**原理上做不到**的能力：
  权重永远输出分布采样，不存在「拒答」这个状态。
- 精度-召回是阈值旋钮：thresh=3.0 时幻觉 0% 但高噪声召回保守（28/50）；
  可按场景调（产品建议双档：闲聊模式放宽，知识模式收紧）。
- 全仿真零梯度、零迭代、零反向传播；CPU 秒级。

## 9. 「思维」三实验（hdc_think.py）——第二容器产生软推理的数学验证

修正原判「干不了软规律」：HDC 的**相似度核 + 叠加**就是软机制。
三个思维层全部有解析形式，全部实测验证（D=16384，零梯度）：

### 实验 A：软规则引擎 = 核回归（Nadaraya-Watson）
- 规则库 M = Σ conj(前件)⊙后件 一次写入；查询 = 前件叠加向量
- **数学恒等式**：容器解码分布 ≡ 相似度核预测（实测排序偏差 6.3e-05）
- 判决 = 核分数本身：K_j = Σ_{r:c_r=j} sim(A_r, Q)，置信度 = 首次名间隔
- 特征空间疏散度决定碰撞（核宽 vs 规则密度的标度律）：
  - NF=24（稠密碰撞）：精确 0.600 / 半重叠泛化 0.265
  - NF=64（疏散）：**精确 0.865 / 半重叠泛化 0.310 / 全新组合 0.055（=拒答后随机线，无幻觉）**
- 修正记录：bundle 归一化必须用向量范数（相位归一会破坏叠加正交性，串扰暴涨 20 倍）

### 实验 B：推理链 = 迭代检索
- 正交编码 9 跳链：**精确走通**（每跳 M⊙state → argmax，正交节点下零损耗）
- 起点噪声 10%/20%/30%：**50/50 全部走通**（每跳召回自动去噪）
- 对照：权重容器链式推理 = 误差复利，链越长崩得越快（ans_audit 实锤）

### 实验 C：一次性抽象 = 例子叠加平均
- 从 n 个带噪例子抽共享变换 Ĝ = Σ conj(A_i)⊙B_i / n，泛化到全新对象
- **1 个例子 + 20% 相位噪声 → 200/200 抽象泛化**（全部 9 组配置满分）
- 这是「从个别例子学会规律」的容器化：规律 = 例子的叠加平均

### 思维的数学形式（本节结论）
| 思维层 | 容器机制 | 解析形式 |
|---|---|---|
| 联想（软规则触发） | 叠加规则库 + 相似度解码 | 核回归 |
| 推理（多步链） | 绑定展开 M⊙state 迭代 | 链式代数（正交=零损耗） |
| 抽象（从例子提规律） | 例子叠加平均 | 均值 = 共享变换估计 |
| 拒答（不幻觉） | top1-top2 间隔 z 分数 | 噪声统计分离 |

剩余边界（诚实）：从**原始感知数据**自动学特征表示仍需编码器（小权重或随机
投影）——即「表示学习」未解决，「表示之上的思维」已解决。混合架构：
编码器（唯一需梯度的部件）→ HDC 思维容器（全部局部学习）。

## 10. 对话与推理（hdc_dialog.py）——容器变成「能对话能推理」的机器

架构拆解：**对话 = 工作寄存器 + 叠加事实库**（说话人寄存器做指代解析，
每轮一句话 = 一条 conj(key)⊙value 写进海马体）；**推理 = 知识图谱叠加存储 +
绑定展开**（A→B 与 B→C 两个关系各一个叠加向量 M1/M2，问答 = M⊙头实体 →
解码中转 → M2⊙中转 → 解码终点）。全程零梯度。

### 实验 D：多轮记忆容量律（边聊边记，D=16384）
| 聊天轮数 | 唯一键回忆 | 词典键(400 实体池) | 理论噪声底 √K·1.25/√D |
|---|---|---|---|
| 100 | **100/100** | 80/100 | 0.098 |
| 300 | **100/100** | 62/100 | 0.169 |
| 600 | **100/100** | 31/100 | 0.239 |
| 1000 | 82/100 | 14/100 | 0.309 |

**关键发现：键唯一性是容量硬约束**。唯一键组服从纯噪声容量律（600 轮内满分）；
词典键组证明「两个人叫同一个名字」式的键碰撞就是歧义源——回忆率随轮数坍缩
（80→14），且坍缩与噪声底无关（是结构问题不是容量问题）。工程结论：
对话系统必须给每个事实分配唯一复合键（说话人⊙时间戳⊙话题），实体词直接
当键会自我污染。

### 实验 E：二跳问答容量律（实体无放回，消歧义后纯噪声）
| 每关系边数 K | 一跳 | 二跳 | 理论噪声底 |
|---|---|---|---|
| 50 | 100/100 | **100/100** | 0.069 |
| 200 | 100/100 | **100/100** | 0.138 |
| 800 | 97/100 | 99/100 | 0.276 |
| 1600 | 69/100 | 70/100 | 0.391 |

**准确率衰减精确跟踪理论噪声底 √K/√D**：K≤200 满分，K=1600 时一跳 69% ≈
噪声底 0.391 对应的解码下限——实测曲线与逐点预测吻合（二跳 70% ≈ 一跳 69%
+1，说明跳数本身零损耗，损失全部来自单跳召回噪声，与实验 B 的「正交节点下
零损耗」结论闭环）。这给了**图谱容量的封闭式设计公式**：要保 95% 二跳准确率，
K·(1.25)²/(D) ≤ 阈值 → D=16384 时每关系约 400 条边；扩 D 即线性扩容量。

### 本节结论
| 能力 | 容器实现 | 解析形式 |

## 11. 模型权重的另一条路（hdc_weights.py）——叠加向量组就是「权重」

定位：语言模型的「训练」不必是梯度下降——**权重 = 一组分库叠加向量，
训练 = 对语料一遍纯加法写入（零梯度零反向传播）**。本节用字节级 n-gram LM
做试验田，因为计数 n-gram 表是它的解析对照组：HDC 叠加 LM 应当严格逼近
计数表，偏差由噪声律解析预测——每一步都可验算。

### 11.1 三步架构演进（缺陷→修复的实证链，D=16384，语料 36KB 源码字节流）

**W1 角色-填充键（P[b]⊙Q[role]）＝相干串扰缺陷**：
位置码在共享角色上精确抵消（conj(Q)·Q=1），上下文只差一个角色时
W_j = conj(P[b'])⊙P[b]⊙P[v] 对同类别写入是**同一个常向量**——重复写入
按类别计数**相干叠加**（∝n），不是随机抵消（√n）。对计数表 argmax 的
保真度：c<50 全部 0%，而独立噪声律解析预测 c≥5 为 98%+——系统性背离。

**W2a 单库哈希键＝键复用仍有相干噪声**：每个上下文一个随机键（crc32 种子），
同上下文对齐保留；但上下文重复（平均 4.8 次/键，最高 627 次）时，重复写入
对**其他查询**的贡献是同一个确定向量（W 由 (C_j,C_q,V_j) 三元组决定），
再次相干叠加。受控注入隔离（hdc_debug_weights3.py）：

| 探针背景（16k 写入） | 竞品噪声 std | 独立律理论 | 竞品 max |
|---|---|---|---|
| 无背景 | 0.018 | — | 0.097 |
| 16k 随机键（不复用） | **0.475** | 0.699 ✓ | 2.31 ✓ |
| 真实语料（键复用） | **2.26** | 0.699 ✗ | **14.1**（重尾） |

**关键发现：单库叠加的真实容量律是相干碰撞能量 Σ_c m_c²，不是 √n。**
自然文本的 Zipf 重复使 Σm² ≈ 10×n，单库必败。这同时是 **Kanerva SDM
（1988）必须分库的解析证明**——我们从缺陷实验反推出稀疏分库存在的数学理由。

**W2b 分库（SDM 式哈希分桶）＝设计律恢复**：桶内噪声只剩
σ=√((m_b−c)/(2D))（m_b=桶占用≈127），对表 argmax 保真度
c=1: 93.5% → c≥9: **100%**（解析 100% ✓）。

### 11.3 权重性质四件套（全部实测）

| 性质 | 机制 | 实测 |
|---|---|---|
| **合并** | 逐桶向量相加（线性精确） | 相对偏差 8.8e-14，高置信预测分歧 0/400——语义无损合并（对照：梯度权重合并需蒸馏且互相干扰） |
| **低比特量化** | 相位量化，信号衰减因子 = sinc(π/m) | **1 bit/维（m=2）准确率仅掉 1.5 个点**（50.0% vs 51.5%），4 bit 完全持平；权重体积 64MB fp128 → **2MB（1bit）/ 4MB（2bit）** |
| **持续学习** | 桶占用增长 = √ 可预测噪声税 | 唯一续写子集保真 140/141 → 137/141（共库）；**分库 140/141 → 140/141 精确零遗忘** |
| **容量设计律** | 每桶：P(correct)=E[(1−exp(−s²D/n))^255] | 分库后逐桶实测吻合（c≥1 全 100% vs 解析 100%） |

### 11.4 与既有路线的关系

- **对齐 C 核线**：相位量化 m=4 = 2 bit/维，与三值核/低比特权重视同一条
  工程路线——HDC 给出的是「权重可以低到 1-2 bit 仍保功能」的解析依据
  （sinc 律）+ 无损合并 + 零遗忘三件额外性质。
- **与梯度权重分工**：叠加库管知识/事实/规则（一遍写入、可合并、不遗忘），
  梯度权重管表示/技能（编码器仍是唯一需梯度部件）——混合架构（§10 末）
  现在有了一个能真跑 LM 的知识侧容器。
- **对齐 KB（wiki 库）**：KB 是外置检索，叠加库是「权重化知识」——同一份
  语料两种形态，前者精确可更新，后者低比特可合并。

### 11.5 诚实边界

1. **n-gram 语义天花板**：本节 LM 只有回退链（三→二→一元），无组合泛化；
   超出 n-gram 的推理仍靠 §9 的绑定展开，两者是不同容器机制。
2. **权重体积**：16MB（2bit）装 36KB 语料——叠加权重**不密集**，价值在
   解析规律、可合并、零遗忘、模糊召回，不在存储密度；D·B 是权重预算，
   容量受 Σm² 制约。
3. **表示学习未解决**（§5/§9 同）：字节码仍是随机码本；从原始感知学编码
   仍需编码器。
4. **单库 Σm² 律是普适警告**：任何把重复知识写进同一个叠加库的设计
   （包括 §8 的海马体）在 Zipf 型重复数据下都会撞相干串扰——分库是
   结构必需，不是优化选项。

## 12. 与模型权重「同样性质」（hdc_weights2.py）——容器从记忆升级为函数

模型权重的定义性质有三：**参数化函数**（定义在全输入域，不只响应存过的
键）、**可训练**（从数据经优化收敛）、**可泛化**（对全新输入插值）。本节
把这三条逐一数学验证。

### 12.1 数学核心：容器权重 = 随机相位特征空间的线性读出向量

特征 φ(x)_j = exp(2πi·f_j·x)（f_j 随机整数，去掉 DC）——移不变核的
蒙特卡洛近似（Rahimi-Recht 2007 随机特征定理），核带宽 = 1/(2F)。
权重 θ（D 个复相位 = 2D 实参数）定义 f(x) = Re⟨w, φ(x)⟩/D。两条解法：

- **one-shot 叠加写入**：w = Σᵢ conj(φ(xᵢ))·yᵢ ⟹ f(x) = Σᵢ K(x,xᵢ)yᵢ
  = **未 Gram 归一化的核回归**。要求键近正交（Σᵢⱼ K≈δ）——**记忆域**。
  重叠域失效：f_os(x) = ΣK·y 的相干放大 ∝ n（实测 F=1 时 MSE 7600，
  = n·傅里叶系数的平方，解析精确解释）。
- **delta rule**：w ← w − η·Aᵀ(Aθ−y)/n = **该空间的最小二乘 GD**。
  LS 解 = K(K+λ)⁻¹y = **Gram 归一化后的 one-shot**——训练的本质 =
  除以 Gram 矩阵，把重叠特征从干扰变成插值信息。**函数域**。

**记忆与函数是同一叠加代数的两个域**：键近正交时 one-shot 最优（§3/§8/§9
的全部实验都在此域）；特征重叠时必须 GD 训练（本节）。

### 12.2 实测验证（D=8192，n=300，g=三谐波正弦，σ=0.3）

**A. 可训练**（hdc_weights2.py EXP A）：
| 验证项 | 理论 | 实测 |
|---|---|---|
| GD → 岭回归闭式解（两条独立路径） | 0 | 函数空间相对偏差 **9.3e-16** |
| 逐模衰减定律（单模注入三个模） | log\|1−η(μ+λ)\| | 三个模**逐位吻合**（-0.3567/-0.2005/-0.0812），特征残差 ≤1.9e-15 |
| 复数叠加解码 ≡ 实数权重读出 | 恒等式 | max\|Δf\| = 3.1e-14 |
| 重叠域：one-shot vs GD | one-shot 相干放大 ∝n | 随机采样 8.71 vs **0.0952（≈σ²=0.09）**；聚类采样 24.2 vs **0.16** |

（工程注记：谱含 236 个数值零模——近重复采样点，其"特征向量"是噪声方向，
速率验证必须避开；这本身是采样密度 vs 带宽的几何效应。）

**B. 可泛化**（带宽 F 扫描，测试 MSE 三段曲线，全部对上解析）：
- F<5 偏差段：F=1 实测 0.171 ≈ 解析（缺失谐波能量 0.5²/2+0.3²/2 = 0.17）
- 中段方差 ≈ σ²(1+p/n)：F=8 实测 0.0129
- 灾变段 F>n/2=150：插值噪声爆炸
- one-shot 对照列：重叠域全程 ∝n 放大，仅在 F≳n/2（近正交）时可用

**C. 表达力**：特征采样方差 ∝ 1/D（随机特征定理）——实测超额误差指数
**−1.29**（理论 −1）。

**D. 低比特量化**（HDC 原生相位量化，信号衰减 sinc(π/m)）：
| 相位级 m | ΔMSE 实测 | 权重体积 |
|---|---|---|
| 2（1bit/复权重） | 0.306 | **1.0 KB** |
| 4（2bit） | 0.036 | 2.0 KB |
| 16（4bit） | 0.0070 | 4.0 KB |
| 256（8bit） | 0.000027 | 8.0 KB |

（发现：权重幅度重尾 max/median=17，均匀比特量化器失配且实测非单调——
量化器必须与权重分布匹配，相位量化是 HDC 原生解。）

**E. 合并 / 续训 / 回放**（GD 权重与 one-shot 权重的分野）：
- GD 平均合并：0.114 vs 全量 0.095——合并不精确（损失非对称）
- **朴素续训（只学新数据）：组合目标 0.128 vs 全量 0.113 = 灾难性遗忘**
- **回放续训（新数据+30% 旧数据）：0.120 → 恢复**——与 152M 训练的
  回放纪律（30-50%）完全同构，在权重层面复现了同一条定律
- one-shot 合并：偏差 1.4e-14，线性精确

### 12.3 结论：第二容器的权重版图

| 域 | 键统计 | 最优写法 | 性质 |
|---|---|---|---|
| 记忆域（事实/情节/规则） | 近正交（唯一键/分库） | one-shot 叠加 | 合并精确、零遗忘、sinc 量化 |
| 函数域（平滑映射/技能） | 重叠（连续输入） | delta rule（GD） | 可训练、可泛化、**会遗忘需回放** |

两域同一容器、同一代数，差别只在键的统计几何——这正是"另一条路"的完整
形态：**不必在梯度权重与查找表之间二选一，键的正交程度是连续旋钮**。

### 12.4 诚实边界

1. 本节 = 随机特征 + 线性读出（1 隐层极限）；深度组合结构（多层绑定展开）
   未做反向传播，§9 的链式展开仍是前馈代数而非学习所得。
2. g 须在核的 RKHS 内（带宽覆盖信号谱）；谱外结构不可表达——表示学习
   （学特征本身）仍是编码器的职责，随机特征只保证核类函数。
3. GD 权重失去 one-shot 的精确可合并性与零遗忘——两域性质互斥是定理级
   事实（线性 vs 二次），不是实现缺陷。混合用法：知识用 one-shot 库，
   技能用 GD 训练库，接口待设计。


## 13. 能力对齐：模型权重能做什么，容器就做什么（hdc_parity.py）

§12 验证了容器权重「是权重」（参数化/可训练/可泛化）。本节反过来从
**功能清单**对齐：权重在每个能力项上做到的，容器逐项复现并给出数学对照。
三组实验（EXP F/G/H），全部纯容器代数（叠加、内积、局部更新），零反传、
零外部优化器。

### 13.1 EXP F：非线性决策面（核读出 vs 线性基线）

数学：随机相位特征 φ(x)_j = exp(2πi·f_j·x) 的线性读出 = 核机器
K(x,x') = E_f[exp(2πi·f·(x−x'))]，**决策面是特征空间里的超平面 =
原空间里的非线性曲面**。权重的线性层做不到 XOR，容器核读出可以——
同一套叠加写入门（delta rule 训练）。

| 任务 | 容器核读出 | 线性基线 |
|---|---|---|
| XOR（600 训练，F=1.25） | **1.000** | 0.263 |
| 同心环（400 训练，F=2.0） | **1.000** | 0.518 |
| OOD 拒答（6 个分布外点） | max 核相似 0.019~0.027（全拒 ✓） | 分布内中位 0.996 |

OOD 拒答是**权重没有的态**：核相似度给出「这个输入在不在训练分布内」的
连续量，权重只输出预测值、无法表达「不知道」。工程教训两条（已写进代码
注释）：①格点频率的核是周期梳，散乱数据相似度全零——频率必须连续均匀；
②核宽 1/(2F) 须 ≥ 数据间距与簇半径（F=6 对 n=600 直接不可分）。

### 13.2 EXP G：离散表示自学习（核 mean-shift EM）

数学：责任 = softmax(β·⟨φᵢ, p_k⟩/D)，M 步 p_k ← Σ r·φ / Σ r
= **叠加写入的加权形式**；LSE 目标 max+log(Σexp(β(S−max)))/β 在 soft
EM 下严格单调（实测 0.240→0.408 单调 ✓）。原型恢复 = 在核空间的密度
峰上爬山（mean-shift 的 EM 化）。

| 验证项 | 实测 |
|---|---|
| EM 目标单调性 | ✓ 40 轮无一轮下降 |
| 原型位置恢复（3 簇，σ=0.05） | **0.0131**（核宽 1/8、簇 σ 量级的统计精度） |
| 责任矩阵 | 对角 0.95+，质量均衡（680/646/672） |
| 新样本归类：学习 codebook vs 随机 | **0.996 vs 0.722** |

**方法学陷阱（烧掉一轮调试）**：表示学习无标签语义，EM 会任意置换原型
顺序——按索引硬对 means_true[k] 得到 [0.51, 0.50, 0.007] 的「假局部
最优」，实为 (0,2,1) 置换假象；误差/归类一律按 3! 最优匹配评估。诊断
结论：k-means++ 式散布初始化（贪心远点）+ β=15 下 EM 一轮都不偏，
责任干净收敛。同类陷阱：网格解码的分块覆盖 bug（每块重写 pos）。

### 13.3 EXP H：连续表示自学习（Oja/Hebb 局部规则）

数学：Oja 规则 w ← w + η·y·(x − y·w)（y = w·x）的不动点 = C 的主
特征向量——**纯局部（每步只用当前样本对）、在线、无矩阵、无反传**。
第二轴用 deflation：X ← X − yyᵀ 后重跑。

| 噪声维 d | cos(w1) | cos(w2) | 子空间恢复 | 学特征 MSE | 随机特征 MSE |
|---|---|---|---|---|---|
| 10 | 0.992 | 0.992 | 0.015 | 0.0149 | 0.142 |
| 25 | 0.9997 | 0.9997 | 0.022 | 0.0152 | 0.422 |
| 50 | 0.969 | 0.969 | 0.031 | 0.0164 | 0.521 |
| 100 | 0.999 | 0.999 | 0.049 | 0.0167 | **0.535** |

下游实验设计：目标 y = sin(2π(x₀+x₁)) 只依赖信号两维，对比「Oja 学到的
2 维特征」vs「各向同性随机特征（d 维全喂给核）」。学习特征 MSE 恒定在
噪声底 0.015~0.017（**免疫维度灾难**）；随机特征随 d 恶化到 0.53
（信号占比 2/d 被稀释）——这正是表示学习的价值：**先压缩再核，胜过
直接核**。主子空间恢复在 d=100 仍 cos>0.999，4096 维容器下 O(1) 局部
更新无矩阵运算。

### 13.4 能力对照总表（权重 vs 容器）

| 能力 | 权重怎么做 | 容器怎么做 | 章节 |
|---|---|---|---|
| 非线性决策面 | 深层网络 | 核读出（特征空间线性=原空间非线性） | §13.1 |
| 离散表示自学习 | 端到端反传 | 核 mean-shift EM（叠加写入的加权形式） | §13.2 |
| 连续表示自学习 | 端到端反传 | Oja 局部规则（在线/无矩阵/无反传） | §13.3 |
| 回归/插值 | GD | delta rule = 核空间 GD | §12 |
| 记忆 | n/a（权重不存键值） | one-shot 叠加，合并精确零遗忘 | §3/8 |
| OOD 拒答 | 无此态 | 核相似度连续量 | §13.1 |
| 合并/量化/持续 | 平均合并不精确 | one-shot 线性精确 + sinc 相位量化 | §11/12 |

### 13.5 诚实边界（在 §12.4 基础上更新）

1. §12.4 第 2 条部分解除：表示学习不再是「编码器的职责」——离散原型
   （EM）与连续主轴（Oja）都能在容器内自学习；但仍限于**浅层**：
   EM 学的是密度原型、Oja 学的是线性子空间，多层组合特征（深度表征）
   仍待做。
2. EM/Oja 都只保证**局部最优**（EM 单调但依赖初始化；Oja 收敛到主轴
   前提是学习率满足 Robbins-Monro 且初始向量与主轴不正交）——与
   神经网络相同，不是容器独有缺陷。
3. Oja 只提取前两轴（deflation 链可扩展到 k 轴但误差逐轴累积）；
   完整谱 = 幂迭代族，仍是局部规则族。


## 14. 彻底走通：§13.5 挂账三项拆除（hdc_parity2.py）

### 14.1 EXP I：深层组合的反传训练（挂账①拆除）

架构：h = tanh(A₁·W₁ᵀ)（A₁ = φ₁(x) 实相位特征，H 隐单元）→
out = Re⟨w₂, φ₂(h)⟩/D₂（第二层容器读出）。两层都是容器代数，反传穿过
两层容器层的链式恒等式：

  ∂out_j/∂h_i = −(2π/D₂)·Σ_k f₂[k,i]·Im(w₂_k·φ₂_jk)   （纯 Im-内积，解析）

| 验证项 | 实测 |
|---|---|
| 解析梯度 vs 中心差分（12 入口） | **6.3e-09**（恒等式精确） |
| 手工 Adam 训练 3000 步（7 秒，无优化器库） | test **0.988**（奇校验-3） |
| 冻结随机第一层（同架构同预算，只训 w₂） | 0.863 → **特征学习增益 +12.5pp** |

**诚实对照（负面结果入档）**：奇校验-4 同预算 256 实参——单层核
**0.910** vs 两层容器 3 种子 **0.746~0.772**。小预算下深度是劣势
（优化难度 > 表达力增益）；奇校验-3 上单层核也 1.000（随机频率命中
parity 谐波窗口的测度 ≈ 6%，比直觉高一个量级）。结论：**深度不是
免费午餐，其收益在同架构特征对齐（冻结对照），不在「核做不到我能做」**；
随机特征带宽覆盖足够时核是最强基线。

### 14.2 EXP J：值域乘法编码（挂账②拆除，绑定代数）

值域码 c(v) = exp(2πi·f·v)（f 独立随机频率族）。三条恒等式全部机器验证：

| 恒等式 | max\|Δ\| |
|---|---|
| J1 绑定 = 值域加法：c(v₁)⊙c(v₂) ≡ c(v₁+v₂) | 1.4e-14 |
| J2 log 同态：c(log v₁)⊙c(log v₂) ≡ c(log v₁v₂)——**乘法结构在码域变平移** | 7.1e-15 |
| J3 绑定 = 平移算子：⟨c(y), c(x)⊙c(δ)⟩ = K(y−x−δ) | 5.3e-16 |

**J4 三重绑定乘法表叠加记忆**（功能演示）：
B = Σᵢ c₁(aᵢ)⊙c₂(bᵢ)⊙c₃(aᵢbᵢ)，M=25 条记录零训练解析写入一个 8KB 码。
查询 U = conj(c₁(a))·conj(c₂(b))·B 后网格扫描解码乘积：

| 验证项 | 实测 |
|---|---|
| 精确键查询解码误差（25 条） | **0.0000**（max） |
| 键噪声 +0.04（核主瓣内） | 0.0000（峰位不动，优雅退化） |
| 未存键 | 落在已存乘积核邻域（**核回归插值语义，不幻觉**） |

**工程教训（烧掉一次实测）**：三槽位用同一频率族时叠加只编码总和
a+b+p——查询峰被等高干扰峰淹没（实测解码误差 mean 3.89）；**角色分离
必须用独立频率族**（经典 HDC role/filler 纪律），交叉项相位不相干后
干扰 ∝ 1/√D，解码精确到网格步长。

语义对照：权重学乘法要靠训练收敛；容器是**解析写入 + 绑定代数还原**
——乘法表的存储成本 O(M·D) 且单码内可叠加，查询 O(网格·D)。

### 14.3 EXP K：Oja deflation 链（挂账③定量收窄）

30 维、3 个信号轴（特征值 0.998/0.354/0.123，噪声维 0.003），deflation
逐轴提取：cos(w_k, v_k) = **0.9976 / 0.9982 / 0.9974**——第三轴无衰减
（本谱隙下误差累积 < 0.003，谱隙大时 deflation 残差被主轴支配）。

## 15. 走通下半场：深层堆叠、开销定量与记忆×函数接口（hdc_parity3.py）

### 15.1 EXP L：三层容器堆叠（挂账③拆除——数学✓，优化墙诚实入档）

**同一恒等式的逐层复用**：中间层读出 u_i = Re⟨w_i, φ(h)⟩/√D 与输出层
out = Re⟨w, φ(h)⟩/√D 是同一个代数形式，其链式恒等式

  ∂Re⟨w,φ(h)⟩/∂h_k = −(2π/√D)·Σ_m f_mk·Im(w_m φ_m)

对**任意一层**成立——三层堆叠的解析梯度 = 该恒等式沿层链复用（每层一个
einsum）。机器验证：三层全参数 16 入口梯度检查 **8.6e-10**。

| 配置 | 奇校验-4 test | 奇校验-3 test |
|---|---|---|
| 三层容器（H=8,8；D=32,32） | **0.490（随机水平，优化失败）** | **0.848 ✓** |
| 两层容器（预算匹配 912≈1120） | 0.862 | 0.980 |

结论：**恒等式逐层组合在数学上无障碍（梯度精确），但 plain Adam 的
优化难度随深度×任务难度陡增**——三层败奇校验-4 而胜奇校验-3，是
难度墙不是结构墙。skip 连接与残差两种经典解药实测无效（均 ~0.53），
深层容器的优化器设计（二阶/课程/谱归一）是真实开放议题。

### 15.3 EXP N：记忆域×函数域接口（§12.4 第 3 条「接口待设计」拆除）

**设计**：键距 = 核零点（1/(2F)）⟹ 存键处 one-shot 读出精确（记忆域
纪律）；函数域容器 f(x, m) 由 delta rule 训练，其第二维输入 m 由

| 验证项 | 实测 |
|---|---|
| N0 one-shot 读出在 8 个存键处 | max\|Δμ\| = **2.2e-16**（精确） |
| N0' 码域 unbind+网格解码 | 0.0033（网格步长 0.005 内） |
| N1 旧 8 类端到端 test MSE | mean **0.0009**（噪声底 0.0025 以下） |

**语义**：这就是容器版的「检索增强」——新知识 = 一次叠加写入 +

①键必须放在核零点格上（正交纪律，§3 同源）；②读出语义 = J3 平移

## 17. 优化墙裂缝：残差恒等通路 + 闭式头（hdc_debug_grow.py + EXP P）

### 17.1 机制假设与决定性对账

plain 三层的 h₂ = tanh(随机读出) 是**任意随机变换**——顶点身份被搅浑，
头无法解码 ⟹ 只能走记忆化盆地（§16 签名的机制解释）。新假设：给层 2
一条**恒等通路** h₂ = h₁ + tanh(u₂)（W₂ 微初始化），配合**每步岭回归
闭式头**（头部永远最优 ⟹ 隐层面对稳定回归目标，记忆化/不稳定双通道
被掐断）。

对账实验（决定性）：同一训练好的 h₁ 特征上，GD 头与闭式头 test 完全
一致（0.706 = 0.706）——**闭式头无损**，配方劣化只能来自别处。

### 17.2 定量发现：残差抖动-核衰减律

插入层的微初始化幅度 σ 不是小事：每维保留率
ρ = E_{f~U(−F,F)}[exp(−2π²f²σ²)]，d 维**连乘** ρ^d。
σ=0.05 时（初版配置）10 维只剩 0.52——同簇相似度腰斩，闭式头欠拟合
（train mse 0.80）的机械根因。压到 σ=0.01 → ρ^d = 0.90 量级可接受。

| σ | 实测保留率 | 解析 ρ^d |
|---|---|---|
| 0.005 | 0.9933 | 0.9934 ✓ |
| 0.020 | 0.8998 | 0.9004 ✓ |
| 0.050 | 0.5189 | 0.5267 ✓ |

三条实测全对上解析——**残差层微初始化的幅度预算公式**（工程可直接用：
σ ≤ 0.02·核宽对应量级 / 由 ρ^d ≥ 目标值反解）。

|---|---|

| **grow 配方 v0**（残差+闭式头+小步长） | **0.673±0.016**（D48）/ 0.681±0.028（D96）/ 主脚本 0.710 |

**墙裂开**：随机水平 → 稳定 0.67-0.71（+19pp，方差 ±0.02 极小——配方
消掉了种子敏感的盆地选择）。**未推倒**：仍差两层 ~8pp——深度在此任务
上仍无优势（与 §14「小预算深度劣势」一致），但「三层必死」已破。

### 17.4 配方要点（容器原生深训 v0）

1. 每个新插入层走残差形式 h_ℓ = h_{ℓ−1} + tanh(u_ℓ)——恒等通路保证
   初始即等价于浅层网，信息无损耗。

## 19. 串联式生长（concat-growth）：深度劣化第二成因判定

### 19.1 假设与构造

§18 判定深度单调劣化，头号嫌疑=叠加式残差的「核几何漂移税」（§17.2
衰减律 ρ^d）。§19 检验对立构造：**串联式生长**——新层输出不移动旧
坐标，而是作为新坐标附加（h_new=[h_prev, t]），头按块分治（每段独立
fos，vo 分块）。旧块几何结构不变 ⟹ 深度单调性应有构造性保障，且新
块无衰减税。配方沿用 §17 裂缝全家桶：残差恒等通路+W 微初始化（0.3）
+分块闭式头（λ=1e-4）+小步长 Adam。梯度检查：单条目 9 入口
最大相对偏差 1.36e-04（中心差分二阶地板；逐条目 ratio 1.000）。

### 19.2 R 扫描：假设判负

| L | concat（3 种子） | 对照 叠加式 §18 | train mse |
|---|---|---|---|
| 1 | 0.709 ± 0.038 | 0.749 | 0.000 |
| 2 | 0.533 ± 0.011 | 0.655 | 0.000 |
| 3 | 0.527 ± 0.017 | 0.599 | 0.283 |
| 4 | 0.505 ± 0.025 | 0.533 | 1.183 |

1. **深度单调劣化依旧**（0.709→0.533→0.527→0.505）：构造性保障没有
   兑现。L≥3 略优于叠加式，L=2 反而更差（0.533 vs 0.655）。
2. **利用率平坦**（0.23-0.28，无衰减迹象）：几何前提成立——旧块确实
   没被移动。**但深度照样劣化 ⟹ 衰减律不是主因**。
3. **墙移动到了优化内部**：train mse 随深度爆炸（0/0/0.283/1.183）。
   L≥3 连训练集都拟合不动——失败不再是泛化问题，是 W 在高维 φ 输入
   （hin 维=jH 递增→频率维递增）上的优化问题。
4. **L=2 的精确拟合陷阱**：train mse 0.000 但 test 0.533（低于 L=1 的
   0.709）——更深的特征空间找到了「精确拟合但不泛化」的解盆地，
   闭式头把坏 W 的特征精确组合了。
5. **R2 两时间尺度**（新层 lr=0.02）：0.492/0.517，无救。

### 19.3 工程记录：广播 bug 与「整列差分归零」陷阱

1. **广播 bug**（本轮 1.09 偏差的根因）：链入累加写成
   `dseg[k//H] + chain[:, k:k+1]`——(n,H)+(n,1) 广播，每列都被加上
   chain 全列，正确写法=`dseg[k//H][:, k%H] += chain[:, k]`。
2. **定位方法论**（值得留用）：整列扰动数值对照给出「梯度≈0」的假象
   （chk2 误报两次）。逐样本单条目扰动才可信：头块0 与链入两条路径
   分别 1e-8/1.7e-8 验证通过，最后用手工链式（已验证的 dL/dsegs0 →
   (1−s²)→T@A1）对照 gs[0] 抓出唯一残差=累加步。
3. **整列差分归零陷阱**：闭式头解处 Aall^T·r=λn·vo ⟹ Σ_n r_n·φ=
   √D·λn·conj(w)，而 Im(w·conj(w))=0——整列中心差分恒为零。教训：
   **梯度检查永远单条目扰动，永不整列**。

### 19.4 对 §18 结论的修订

深度劣化是**双因子**的：①几何耦合（叠加式专属，§17.2 衰减律）——
concat 已拆除；②**深层 W 优化难度**（深度无关构造，hin 维随深度增长
放大）——concat 拆不掉，且拆掉①后它独占劣化。加上 L=2 的精确拟合
陷阱，「深度红利存在条件」的候选方向收敛为：控制 φ 输入维的增长
（段间共享频率子空间/低秩 f）、或对新层 W 用 §16 式干预逐个排除。
原 18.4 第 3 条的「残差方向正交化」路线被本轮间接证伪（concat=最彻底
的正交化，仍劣化）。



## 20. 深度税定案：排除法收口与「纯附加单调性」

### 20.1 §20 实验矩阵（hdc_debug_subspace.py，梯度检查 ~5e-9）

| 实验 | 设计 | 结果 (L=1..4) |
|---|---|---|
| S2 全绑定 | 每段同 F0 同 W0，参数恒定 640 | 0.723/0.533/0.512/0.483 |
| S3 频率共享 | 每段同 F0，W 独立（参数仍增长） | 0.745/0.533/0.520/0.498 |

| S7 分阶段生长 | 阶段1 只训 W1 → 阶段2 冻结 W1 只训 W0 | 0.723→0.665，单调率 0/3 |
| S7b 纯附加 | 阶段2 附加随机层，W0 零训练，闭式头裁决 | 0.723→0.723（Δ≈0） |
| S7c 强脊 | 阶段2 λ=1e-2→1e0 | 无救援且更糟（λ 压扁 block0） |

对照：§19 concat L=1..4 = 0.709/0.533/0.527/0.505；§18 叠加式
0.749/0.655/0.599/0.533/0.481。S2/S3/concat 在 L=2 的逐种子数字完全
一致（同 rng 流同形状 → 同初始化；也说明 L=2 吸引子对第二层初始化
不敏感）。

### 20.2 排除法收口：深度税的唯一幸存解释

逐个排除：①几何耦合（§19 concat 拆）→ 仍劣化；②参数/景观增长
（S2 恒定参数）→ 仍劣化；③头容量（S4 头加倍不劣化）→ 排除；
④头正则可救（S5/S7c）→ 排除。**幸存解释=新层 W 的梯度训练动力学**：
train mse 在 L≤3 已插值饱和（≈0），残差里只剩噪声，任何对 W0/W1 的
梯度步都在放大噪声拟合方向——S7（训 W0）−0.06、全栈共训 −0.19、
S7b（零训练）Δ≈0，伤害量与 W 训练量单调正相关。

### 20.3 构造性单调的兑现边界

S7b 证明 §19 的构造性承诺在「**纯附加**」形态下成立：附加随机层
+闭式头重解，旧块几何零移动+ridge 收缩无用块 ⟹ test 逐字节不动
（Δ≤0.002）。但纯附加也无增益（随机层不添信息）——**单调但没有
红利可积累**。深度红利在本任务规模是数学上无空间：L=1+闭式头已把
train 插值到 0，深度没有可拟合的真实结构留给它；它唯一能做的事
（拟合残差）恰好全部是噪声。

### 20.4 终版结论（修订 §18.4/§19.4）

1. 容器深训战役（§15-§20）收口：深度单调劣化的机制=W 训练动力学
   ×插值饱和，与几何/参数量/头容量全部无关；在插值饱和的任务上
   深度红利数学上无空间。
2. 生长配方 v1 定版：**生长=纯附加+闭式头重解**（构造性单调、
   零伤害）；W 训练只在「L=1 尚未插值饱和」（train mse>0）的任务上
   才有正空间——那是下一战场（更难任务/更小头/更大噪声），不是
   本规模的。
3. 工程遗产：绑定权重梯度须跨层求和（S0 首查 9.25e-02 → 修后
   4.8e-9）；s2=0 时循环体不执行导致头从未求解的假结果（打印
   mse=1.000=预测全零，先无条件解一次头修复）；均匀 λ 非块选择
   正则会同时压扁旧块（S7c 反向证据）。

### 20.5 深度上限扫描（S8）：「能做几层」的完整答案

纯附加形态堆深扫描（层0 W1 按 L=1 配方训练=唯一训练，层 1..L−1
随机 W 冻结，闭式头一次重解，3 种子）：

| L | w2=0.3（标准随机） | w2=0.01（近恒等） |
|---|---|---|
| 1 | 0.745 → 0.745 (Δ0) | 同左 |
| 2 | 0.723 → 0.723 (Δ−0.001) | 0.723 (Δ−0.001) |
| 4 | 0.752 → 0.751 (Δ−0.001) | 0.752 (Δ+0.000) |
| 8 | 0.743 → 0.743 (Δ−0.001) | 0.745 (Δ+0.001) |
| 16 | 0.744 → 0.719 (**Δ−0.025**) | 0.744 → 0.743 (Δ−0.001) |

1. **结构上限实测 ≥16 层**：w2=0.01 时 16 层仍逐字节无损；w2=0.3 在
   L=16 出现 −0.025 的轻微税（15 个随机块 ×64 参数开始拟合残余噪声，
   头块范数 block0=4.06 vs 随机块 ~0.6 可见分配）。
2. **上限的性质是数值的，不是架构的**：头 solve（L=16 时 1024 维
   ridge）与 φ 链在 16 层深都没崩；衰减全部来自「随机块给闭式头
   递噪声拟合自由度」，小初始化 w2 即可压住。
3. **层数的三分答案**（本任务规模，parity-4/600 样本）：
   - 训出收益的层数 = **1**（L=2 起悬崖，§18-§20 全部变体证毕）；
   - 纯附加无损可堆层数 = **≥16（实测），数值极限待探**；
   - 有意义的层数 = 0——随机层是死重，16 层与 1 层 test 完全一致。
4. 深度要产生真实红利的前提：L=1 头插值不饱和（train mse>0）的
   任务——更难任务/更小头/更大噪声；那时「纯附加保底+逐层小步
   训练+块级正则」是候选配方，风险=§20.2 的噪声拟合动力学。



## 21. 深度悬崖修复：margin 目标 + 初始化尺度 + 步长（问题解决）

### 21.1 三刀修复与证据（hdc_debug_margin.py / hdc_debug_final.py）

| 干预 | 效果（parity-4, 3 种子） |
|---|---|
| **margin 目标**（L=mean(relu(m−y·out)²)，m=0.9） | L=1: 0.723→0.781；配 w2=0.01 → **0.813** |
| **新层初始化尺度 w2** | L=2: 0.3→0.560 / 0.1→0.652 / 0.03→0.687 / **0.01→0.706** / 0.003→0.689（甜点 0.01） |
| **步长/步数**（lr=0.03, 8000 步） | L=2: 0.680→0.742 |
| **定版表**（m=0.9+w2=0.01+lr=0.03+6000 步） | L=1..4 = **0.725/0.739/0.697**/0.514 |

1. **悬崖拆除**：L=2 从 0.533→0.739，**首次超过 L=1**（+0.014）；
   L=3 中性（0.697）。深度从「灾难」修到「中性偏正」。
2. **机理定位**：悬崖=三伪影叠加——①新层 w2=0.3 随机初始化天生带
   高频扭动特征，梯度下降抛光成记忆化盆地（w2 扫描单调恢复证实）；
   ②mse 目标在插值后梯度消失、Adam 归一化放大噪声（margin 截断
   证实）；③深层需要更大步长（lr 扫描证实）。
3. **margin 的独立价值**：插值后分界面继续被推离样本（max-margin），
   梯度不消失且方向=扩真分界面——L=1 绝对值 +0.09（0.723→0.813）。
4. L=4 失败是**工程性**的（train acc 0.626=深层优化不动，需分层
   lr 课程），不是机制墙。

### 21.2 深度红利的剩余边界（诚实记录）

parity-4 上 L≥2 的 margin 若阶段1 已全满足（viol=0）则新层梯度恒为
零（阶段化 Δ=0.000 的真相）——train 信号耗尽后深度无活可干。任务轴
三档穷尽检验：易（σ=0.1，结构整体抓住+饱和）、难（parity-8×6000，
L=1 就 0.495 纯记忆化）、歧义（σ=0.5，train acc 1.0 但 test 0.51 全
记忆化）——**「部分结构+未饱和」中间态在 2K 参数容器的 parity 族里
不存在**：特征引擎要么整体抓住结构、要么整体记忆化。深度红利的可证
空间在本规模任务族内已用尽；更大规模/更真实任务族上未排除。

### 21.3 工程遗产

1. 链式 einsum 分解加速：Σ_h dLdu·Σ_d φ·wc·f 中 h/d 可分离 →
   q=dLdu@wc，chain=(q·φ)@f（n·d·k，降 ~10×）；与参考实现逐位一致
   （0.00e+00）。
2. 阶段化 margin 生长的梯度索引：bwd_g 返回 [gW1, gW0…, gvo]，
   冻结 W1 时必须跳位取（曾 (10,64) vs (10,80) 广播错）。
3. margin 目标下 vo 并入 Adam 联训（闭式头退役）——闭式头与 margin
   不可兼得，联训在本规模稳定。
4. exec 链陷阱：debug 脚本互相 exec 时会把上游的整段扫描重跑（本轮
   两次超时根因）——切分点必须选在「定义结束、运行开始」处。

### 21.4 战役总收敛（§15-§21）

深度问题六轮战役闭环：墙（§16）→ 裂缝（§17）→ 递推极限（§18）→
concat 判负（§19）→ 机理定案（§20）→ **悬崖修复（§21）**。最终
状态：容器深堆 16 层结构无损（§20.5）；L≤3 训练中性偏正
（0.725/0.739/0.697）；L=1 绝对性能 0.813（margin）；深度红利的
机理、边界、修复配方全部定案。

### 23.5 v5/v6 ALS 攻坚：学编码 vs 随机编码（2026-11-08 判决）

问题：随机特征+闭式解≈核方法/惰性训练天花板，容器要往权重水平
走缺的是**特征学习**。ALS（交替最小二乘）= 容器路线的正确学习形态：
固定 E 解 W、固定 W 解 E，全闭式零 SGD。e_c 正规方程有解析结构：
Hessian = 字频加权的位置绑定 G 组合（G=W_hdc W_hdcᵀ），GPU 批量解
3000 个 1024² 系统。

| 实验 | 架构 | top1 | top3 |
|---|---|---|---|
| v5 纯 HDC+ALS 4 轮 | 1024 | 0.195 | 0.319 |
| v6 v4 架构+ALS 3 轮（η=0.5, λe=10） | 36024 | **0.233** | 0.370 |
| 对照 v4 随机 E | 36024 | 0.230 | 0.369 |

判决三条：
1. **学习编码确实有效**：纯 HDC 腿上 ALS 把 0.121→0.195（+64%），
   打破「随机编码不可学」的怀疑；但带阻尼才收敛（无阻尼 0.198→
   0.180→0.195 振荡=e-解过拟合训练残差）。
2. **字符级天花板由 n-gram 精确特征决定**：完整架构下 ALS 学 E 只
   +0.002（0.230→0.233）——末 1-3 字哈希 one-hot 已满秩吃掉全部
   局部统计，HDC 腿（随机或学习）在此任务上只有 ~0.005 级余量。
   **学习编码的战场不在字符级，在语义级**（与 §22/§23.3 结论闭环）。
3. ALS 全程零 SGD、单轮 92s（Gram 71s+e-解 21s）——**容器路线的
   「学习」已具备分钟级闭式迭代形态**，这是与权重路线（SGD 万步）
   的本质工程差异。

### 23.6 v9 难负例判决：ALS 超过词面（2026-11-08）

v8 架构不变，检索候选加难负例档：99 个**同对话**回复（共享话题，

判决：
1. **「ALS 超词面」里程碑达成**：难负例下词面 R@1 塌到随机线

   **语义对齐真实存在**，学到的 E 编码了词面重叠之外的接续信号。
2. 随机负例下两者持平（词面已饱和），印证 v8 判断：随机负例测不

### 23.7 v10/v11 对比式闭式解：四臂负结果与设计空间地图（2026-11-08）

在 v9 之上试图把难负例压力塞进训练目标，四臂全扫：

| 臂 | 架构/目标 | hard 峰值 R@1/R@10 | vs v9 峰值 (0.019/0.198) |
|---|---|---|---|
| A μ=0 | +n-gram 袋塔(13k 特征)+ALS | 0.016/0.141 且逐轮恶化到随机线 | 更差 |
| B μ=1.0 | n-gram 塔+强排斥, 冻结 E | 0.011/0.089（随机线下） | 摧毁 |
| C μ=0.3 | n-gram 塔+排斥+池中心化评测 | 0.015/0.127 | 更差 |
| D μ=0.3 | v9 纯字袋 ALS+排斥(池均值目标) | 0.021/0.157 | R@1 微升, R@10 降 |

判决四条：
1. **n-gram 袋塔在检索任务是稀释不是增强**（与 v4 next-char 相反
   ——任务性质不同：next-char 靠精确局部统计，检索靠语义泛化）。
   且 n-gram 在场时 ALS 有害：字向量残差梯度≈噪声，ALS 拟合噪声
   单调恶化。**分工律：n-gram 特征在场→冻结 E；纯学习特征→ALS**。
2. **对话均值排斥 μ 是双刃剑**：μ=1.0 把目标减成噪声（随机线下）；
   μ=0.3 在纯字袋上 R@1 +0.002/R@10 −0.04——中性偏差。闭式排斥
   的信息量不如预期（对话均值≈话题成分的粗代理）。
3. **hard R@1 ~0.02 平台是数据规模瓶颈而非目标函数瓶颈**：10 个臂
   的目标函数工程都没推动它——7.3 万句对的 CPED 太小，语义接续
   信号密度不足。放大路径指向更大数据（LCCC 级）或更深塔（句级
   层次编码），不是更多目标函数技巧。
4. 池中心化评测（候选减候选池均值再取 cos）是与排斥目标配平的
   正确口径，无泄漏（池均值是候选集的函数）。

**§23 收官图**：字符级 0.233（trigram 平价，封盘）/ 语义级 hard
R@1 0.019-0.021（2.1× 词面，ALS 闭式学习实锤）/ 放大杠杆=数据
规模与塔深度。容器路线的学习形态（交替闭式、零 SGD、分钟级迭代）
在两个粒度上都已验证，剩余是工程放大问题。

产物：hdc_r10_lib.py/hdc_r10_run.py（v10 双臂）、hdc_retrieval_
als3.py 升级版（v9+μ 参数）。坑：write_to_file 长脚本两次截断
（「missing filePath」）→拆库文件+运行文件两段写。

### 23.8 v12 数据规模检验：LCCC 30 万对话，平台动了（2026-11-08）

假设：§23.7 判定 hard R@1~0.02 平台=数据规模瓶颈。检验=同一 v9
架构（语义袋+ALS）换 LCCC-base 头部 30 万对话（词元级，空格分词
天然词边界；726,491 训练句对 = CPED 的 10 倍）。

|---|---|---|---|

| **LCCC** | **726,491** | 0.053 / 0.317 | **0.040 / 0.256**（轮2） |

1. **数据规模假设实锤**：10× 数据 → ALS hard R@1 +111%（0.019→

### 23.9 v13/v14 百万句对攻坚：ALS 规模稳定性战役（2026-11-08）

LCCC 300 万对话（728 万训练句对=CPED 100×），流式 ALS（id int16
常驻 GPU，双遍 Gram+散射）。四层 debug 战役，每层都有 mechanistic
教训：

| 臂 | 配置 | hard 峰值 R@1/R@10 | trainL/N 轨迹 |
|---|---|---|---|
| 基线 | 随机 E+闭式岭回归（轮1） | 0.033/0.190（>词面 R@1 0.030） | 8.3 |
| v13a | 绝对 λe=100/2000, η=0.2 | 0.033（轮1 即峰，后劣化） | 8→12→22 |
| v13c | η=0.05 | 同上劣化 | 同爆 |
| v13d | +UNK 冻结 | 0.033 | 同爆 |
| v14b | 精确块 Hessian(Σ W_n²) | 0.033，爆炸更猛 | 8→26→432→8473 |
| v14c | +比例正则 | 奇异崩溃（s1=0 字） | - |
| **v14d** | **比例正则+零计数行保护** | **0.036/0.192（轮3，首超轮1）** | 8→17→757→33632 |

机理链条（四层根因逐层剥开）：
1. **trainL 诊断定位 bug**：训练损失 8.3→22 单调暴涨证明是优化
   bug 不是过拟合——「先看 trainL 再谈泛化」应成铁律。
2. **块内 Hessian 低估**：同字同窗出现 k 次时块二次型是
   Σ_n W_n(c)²（k² 级）不是 Σ_i n_{c,i}w_i²（k 级）——64 词元窗
   高频字差 10-100 倍。
3. **共享塔跨侧交叉项**：−kW(M+Mᵀ) 不定型项进不了 PSD-only
   Hessian → 分塔（E_ctx/E_rep 独立）使每块成为精确凸二次。
4. **绝对正则 vs 尺度跨 5 个量级**：中频字 s1·λ(Gmat)≲λe 时
   e_new ∝ s1·E/λe 爆炸 → **比例正则** H=s1(Gmat+λrel·I) 尺度
   无关。零 s1 字奇异 → 零计数行保护。
5. 残余问题（挂账）：trainL 仍缓升（rep 块或 M 漂移耦合），轮4
   回落——峰值管理仍靠逐轮取峰。

**规模结论修正（诚实）**：v12 的 0.040/0.256（726k）仍是全场最高
——其中可能有「错误 Hessian 恰好当正则」的成分；正确数学下随机
E 操作点随数据 72k→0.015、726k→0.034、7.3M→0.033（~1M 对饱和）。
**数据规模假设部分成立**：绝对能力涨了，但线性闭式的数据收益
在百万句对级趋平——下一步杠杆=句级层次塔/非线性块（容器版的
「加深」），不是继续堆数据。

### 23.11 v15 层次塔块更新定案（trainL 爆炸根因闭环，2026-11-09）

v15 首跑轮1 即崩（hard 0.018 < v14 的 0.033，随后崩到随机线 0.010），
λrel 越调越糟（0.1 → 每字每轮 ~10× 放大，8→426→13214→852239）。
本地最小复现（debug_block.py，合成 N=3000/V=50/D=32 有重复字窗）+
**autograd 三方对账**两轮定位，根因两层，全部实证：

**根因一（主犯）：ctx 块 rhs 漏锚定项。** 块二次型
L(e)=s1·(eM)(eM)ᵀ+线性项 的梯度是 grad/2 = s1·G·e0 − bs[c]，精确块解
e* = H⁻¹(bs[c] + s1·G·e0)。实现把 rhs 写成 s1[:,None]*E_ctx（系数
矩阵 s1·I），恒差 s1·(G−I)·e0 项——M≈I 时无害（v13/v14d 前期正常），
M 漂移后放大（trainL 缓升挂账的真身），λrel 拉大反而经 H⁻¹ 放大偏差
（v15 越调越糟的原因）。
验证链：数值 Hessian 对角与理论 2·s1·G 逐位一致（96.558/31.104/…）；
rel err(bs, grad/2)=2.0 = 精确符号翻转指纹（|−A−A|/|A|=2）；修正块解
单字单调 True。
推论（优雅）：grad/2(e0) = −bs[c]，bs（完整旧 h 的 RM 散射）本身就是
负半梯度；λ→0 时修正解与牛顿步 e0+H₀⁻¹bs 精确等价。

**根因二（从犯）：Jacobi 并行块更新无阻尼过冲。** 单字精确解单调 ✓，
全 V 同时动（Jacobi）互踩——多轮发散（11632→8.1e7）。阻尼扫描：
ω=1.0 发散 / 0.5 先降后升 / **0.25 单调收敛**（11601→11493）/ 0.1 慢。
双塔交替（ctx+rep 各 ω=0.25）6 轮全单调（11601→10928）。
rep 块符号本就对（rep 侧「G」=I，s2·E 不漏矩阵），只补阻尼+s2=0 行保护。

**修复后 v15 五轮实测（7.3M 句对，GPU）**：trainL/N 8.17→4.53→2.70→
1.66 严格单调降（爆炸根治，挂账销案）；hard R@1/R@10：0.018/0.154 →
0.0226/0.2010 → 0.0241/0.2089 → **0.0253/0.2037 → 0.0243/0.1931**
（峰值 @轮4）。

**层次塔判决（诚实）**：vs v14d 扁平双塔（0.036/0.192）——R@10 赢
（0.204>0.192），R@1 输（0.025<0.036）。混合结果非全面胜出：话语级
新近袋改善召回排序（R@10），但 8×24 粒度+AH 权重稀释了精排（R@1）。
「加深」杠杆在此形态下只兑现一半；R@1 修复候选=话语袋权重 AH 重标定
或扁平+层次混合编码，挂账。
