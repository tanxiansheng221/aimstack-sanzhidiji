# 权重的本质与未来形态（研究备忘录 2026-11-06，用户令：研究权重的本质，不信只有一条路）

## 一、权重的本质（三层回答，全有论文）

### 数学层：权重 = 被梯度下降编译出来的压缩程序
训练不是「存数据」，是把数据集**有损压缩**成一个条件概率函数 P(下一位|上文) 的参数。
DeepMind《Language Modeling Is Compression》(arXiv:2309.10668)：LLM 本质是通用压缩器，
702MB 的模型压缩文本击败专用算法——**压缩即智能**（Hutter/Solomonoff 谱系）。

### 电路层：权重里实际住着什么（可解释性三大发现）
1. **FFN = 键值记忆库**（Geva, EMNLP 2021, arXiv:2012.14913）：占参数 2/3 的前馈层，
   key 是模式检测器（检测输入属于哪类模式），value 是输出分布——权重的一半是「Addressable Memory」
2. **Attention 头 = 寻址电路**：归纳头（induction heads, Olsson 2022）实现「查过去→抄答案」，
   上下文学习不写权重，走的是这条电路
3. **叠加态（superposition, Anthropic arXiv:2209.10652）**：特征数 >> 维度数，
   权重以干涉方式超密存储特征——**这正是我们容量墙的物理形态**：
   152M 维度的特征预算被干涉噪声封顶，五科零分不是玄学，是预算耗尽的定量表现
4. **Grokking 相变**（Power, arXiv:2201.02177）：权重从「记忆」到「泛化电路」存在迟来的相变——
   平台期不等于死期，相变需要数据多样性和训练量同时到位

### 哲学层：能力的分配问题
模型能力 = **权重（慢程序）+ 状态（快记忆）+ 外存（事实）+ 工具（外呼）** 的分配方案。
未来形态的演化史就是这个分配方案的重新划界——我们已经在做：KB 外置知识、C 核外呼算术，
都是「把不该权重管的东西从权重里挪出去」。

## 二、凭什么下一词预测能「担任」出智能
预测文本要预测得好，必须隐式建模文本背后的**生成器**（世界状态）。
Othello-GPT（arXiv:2210.13382）：线性探针从权重里恢复出完整棋盘世界模型——
权重长出世界模型是实证，不是信仰。

## 四、最锋利的四个结论
1. **容量墙的本质=叠加态干涉极限**——扩容、深窄化、LoRA 分科都是在绕它，绕不开的只能外置
2. **RWKV-7 是唯一与我们基建完全兼容的范式级替代**（无自定义 kernel、ROCm 友好、端侧恒定内存）——
   值得作为 3-6 周的架构对照实验分支，与 Transformer 主线并行
3. **TTT 是「权重的未来形态」本身**：慢权重装技能、快权重装当下——但它还在研究期
4. 短期主线不变：路 1 数据收尾 → 路 2 词表换血（这两步的产物对任何未来范式都是基建）

主线照走（A/B 判决 → E2），RWKV-7 移植列为平行的架构预研分支（不占训练预算，纯本地代码工作），
MTP 头放进下一次 trainer 升级。
