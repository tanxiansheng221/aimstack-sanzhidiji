## 一、被忽视的最大乘数：分词器（本次推演的核心发现）

**字节级编码 = 每个汉字 3 token、每个英文词 4-5 token——模型要学的序列长度是 BPE 模型的 3-4 倍，
等效含义密度被吃掉一大块。** 同样 10 亿 token 的算力，BPE 模型「读到」的含义是我们 3-4 倍。

论文两侧证据：
- **正方（标配派）**：SmolLM-135M（49k 词表）、TinyStories（GPT-Neo 50k）全部 BPE——小模型标配，
  embedding 占参数 20-30% 是公认可接受代价
- **反方（字节派）**：Meta 2024 纯字节+动态 patch 架构（10 万词表砍到 256 字节）小模型反超 Llama 3.2——
  **字节不是死路，但需要 patch 化架构改造**（工程量大）

**判决：BPE 化是性价比最高的未动用杠杆——等效算力 ×3-4，零架构风险。**

## 二、三条路（按启动顺序，不是三选一）

### 路 1（立刻走）：数据工程收尾 152M
- 机械修复已定位：LCCC 去分词、合成故事降比/增多样性、回放补双语对话锚
- 每 4.7h 一段，每段预注册对账
- **判决点：E2 毕业 gen_chat 可读句 ≥3/9 且 frozen loss 回到 ≤1.8 → 继续加段；否则转路 2**
- 与一切后续路线兼容：干净语料是所有路线的基建，一秒不白费

### 路 2（E2 判决后启动）：词表换血 BPE + 从头重训
- sentencepiece 在自家干净语料上自训 16-32k 词表（含数字单字符保算术）
- 模型 152M→重算（embedding +~30M，可 D1536→D1400 补偿）
- 成本：~23h 重训 1.4B token，但每 token 含义 ×3-4 ≈ 等效吃到 5B token 的老模型
- **这是从「碰壁」到「标准赛道」的换轨**： SmolLM/TinyStories 的全部方法论直接适用

### 路 3（容量墙确认才动）：架构三件套
- MobileLLM 深窄配方（40 层 D1152）+ 块级权重共享（免费 +0.8 分）
- MTP 多 token 预测头（arXiv:2404.19737：样本效率提升+推理 3× 加速，改trainer 一天工）
- MathGLM 原子步 + 槽位调用并存（已验证管线）

### 远期形态（记录在案，不排期）
- 字节主权路线：Meta BLT 式动态 patch（若坚持 byte-level 主权）
- 蒸馏路线：开源 0.5B 教师在自家语料上 on-policy 蒸馏（语言习得最快捷径，
  **但引入外部权重依赖，与全自研铁律冲突，需用户拍板**）
- 端侧 MoE（1.5B 时代）

## 三、决断树

```
A/B 对照实验（进行中，~50min）
  ├─ A 稳 B 垃 → 毒包实锤 → 修复数据 → E2（路1）→ gen_chat≥3/9?
  │                                              ├─ 是 → 继续路1 加段至对话成句
  │                                              └─ 否 → 路2 换词表从头训
  └─ A 也掉 → 管线/训练器有病 → 停，修 trainer（推演优先级最高）
```

## 四、纪律（不变）
单变量、预注册、统一量尺、验尸前置、数据集曝光 ≤5 epoch、回放 ≥20% 常驻。
