## 一、五篇支柱论文的证据表

| # | 论文 | 核心结论（定量） | 对我们的用途 |
|---|---|---|---|
| P1 | SmolLM / SmolLM2（HF, 2024） | 135M 流利需 **600B token 精选语料**；FineWeb-Edu 占 ~87%（220B）；**小模型对数据噪音更敏感**；单数据集重复 ≤4-5 epoch | 数据质量>数量的总纲；epoch 上限红线 |
| P2 | TinyStories（arXiv:2305.07759） | 合成简单故事让 3M 模型流利——**窄域高质量数据可大幅压低开窍 token 门槛** | 中文合成故事的合法性证明：纯语言开窍的加速器 |
| P3 | Simple and Scalable Strategies to Continually Pre-train LLMs（Apple, arXiv:2403.08763） | 回放 **1-5% 显著减遗忘，5-10% 最佳平衡，10-50% 减遗忘更多但拖慢适应**；分布偏移越强回放要越多；**重热+重衰减 LR 最优** | lang6 洗掉 lang4/lang5 的解药：强偏移场景回放取 **15-25%** |
| P4 | Data Mixing Laws（复旦, arXiv:2403.16952） | loss 是混合比例的**可预测函数**：小模型上拟合，外推大模型；优化配比=白赚 48% 步数 | 配比不再拍脑袋：用 15M 玩具模型先跑配比拟合实验（零积分本地可跑） |
| P5 | MobileLLM（Meta, ICML 2024, arXiv:2402.14905） | 亚十亿模型**深窄>宽扁**；块级权重共享免费 +0.8 分 | 未来扩容（若数据判决指向容量墙）的架构依据 |

## 二、语料选型（每项带依据）

| 语料 | 来源 | 规模 | 选用依据 | 拿法 |
|---|---|---|---|---|
| **LCCC 中文对话** | 清华 CoAI（NLPCC 2020 best paper） | 12M 多轮对话（从 9000 万原始两阶段清洗） | 论文级清洗管线（规则+分类器），比 CPED 剧本对白干净；微博短对话=真实口语分布 | hf-mirror `thu-coai/lccc`（github 版在百度网盘/GDrive，不走） |
| **中文合成故事** | 自产（TinyStories P2 配方） | 目标 200 万篇短故事 | P2：窄域高质量合成数据是开窍加速器；生成器+验证器本地零成本 | 模板+词表约束生成，每篇过完整性校验 |
| **中文维基** | 已在本地 KB（zh 77.6 万条 FTS5） | ~77.6 万条 | 知识轴已验证零反爬、标题→摘要键值对 | 从 KB 导出，不用重新爬 |
| **TinyStories 英文** | roneneldan/TinyStories | ~2B token | P2 原版语料；英文第二语言的打底教材 | hf-mirror 直下 |
| **算术原子步** | 自产（MathGLM arXiv:2309.03241 配方） | 目标 200 万条分步链 | P5 段已验证：C 核管线通、缺的就是这个形态的数据 | Python 生成器，全链求值验证（全有全无律） |
| **13 科考卷对齐回放** | 既有 pool_fmt_*.npz / v2 语料 | 按回放比例 | P3：回放防遗忘；考卷格式对齐=训练分布=考场分布 | 已在实例持久化 |

**不选/后置**：多语种第三语言（P4 证据：预算固定时铺语言=全线平庸，中英流利后再一次加一个）；OSCAR/CommonCrawl 原始网页（清洗成本>收益，FineWeb-Edu 级过滤管线我们没有）。

## 三、配比定版（有据可查的初版）

**主段（语言先行，用户拍板）**，总窗口按 15 万窗计：

| 成分 | 占比 | 依据 |
|---|---|---|
| 中文合成故事 | 25% | P2 开窍加速 |
| LCCC 对话 | 20% | 对话分布 |
| 中文维基 | 10% | 知识轴打底 |
| 英文 TinyStories | 15% | 英文第二语言 |
| 13 科考卷对齐回放 | 20% | P3 强偏移取上限区间（10-50% 中偏下，兼顾适应速度） |
| 算术原子步 | 10% | MathGLM：从第一步就混数学（SmolLM2 社区参考配比数学 14% 同向） |

**纪律**：任何单数据集曝光 ≤4-5 epoch（P1 红线）；算术/科目回放每段必带，永久条款。

## 四、执行序列

1. **零积分下载+生成**（立即可做）：LCCC 探测下载 → 合成故事生成器 → MathGLM 生成器 → 维基导出 → 混合打包 lang7_pack（peek 验尸必过）
2. **配比拟合实验**（可选，P4 方法）：15M 玩具模型 × 4~5 个配比点，各 3000 步，拟合 loss(比例) 曲线，校准上表——本地 CPU 一晚，零积分
3. **E1 发车**：152M 从 lang6 续训 15000 步 ≈ 4.5h，预注册预测另发
4. 毕业对账：eval_lang_loss（冻结验证集）+ 13 科考试 + gen_chat 三尺同测

## 五、参考配比外证（社区 10B 级小模型方案）

中文 web 30% / 英文 web 28% / 代码 20% / 数学 14% / 书籍 5% / 合成教材 3%
